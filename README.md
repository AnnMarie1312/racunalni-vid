


Image Processing and Computer Vision
Project Description
This project focuses on image processing and computer vision techniques using Python and OpenCV. The main goal is to explore different image processing methods, detect image features, remove noise, and perform image segmentation.

The project includes experiments with image filtering, feature detection, edge detection, and cell image segmentation.

Technologies Used
Python
OpenCV (cv2)
NumPy
Matplotlib
Jupyter Notebook
Project Tasks
1. ORB Feature Detection
Creating an ORB detector.
Detecting keypoints and computing descriptors.
Visualizing detected keypoints.
Matching features between two images using Brute Force Matcher.
Comparing images using feature matching.
2. Image Convolution
Implementing convolution using pure Python.
Implementing convolution using NumPy.
Comparing execution times of both implementations.
Applying different convolution kernels to images.
3. Image Filtering
Gaussian Blur for image smoothing.
Sharpening filters.
Sobel and Laplacian filters for edge detection.
Applying edge detection after image blurring.
4. Image Thresholding
Converting images to grayscale.
Applying Otsu's thresholding method.
Converting grayscale images into binary images.
5. Morphological Image Processing
Creating a 3×3 structuring element.
Applying morphological opening to remove noise.
Applying dilation to determine the sure background area.
6. Distance Transform and Watershed Segmentation
Applying distance transform.
Normalizing the distance transform image.
Identifying cell centers and background regions.
Preparing images for Watershed segmentation.
